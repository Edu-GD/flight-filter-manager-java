# Flight Filter Manager Java
## App - Filtrado de vuelos por fecha
La aplicación **Filtrado de vuelos por fecha** es un proyecto desarrollado con Java para gestionar y filtrar vuelos utilizando `LocalDate`, **Streams** y **programación orientada a objetos**.

## Tecnologías utilizadas
**Lenguaje:** Java 21  
**Entorno de desarrollo:** IntelliJ IDEA  

## Uso del programa
1. Clona el repositorio:
2. Abre el proyecto en tu IDE (IntelliJ IDEA).
3. Ejecuta Main.java.
4. Añade vuelos en Main.java.
5. Cambia las fechas de filtrado para ver cómo se muestran los vuelos según el rango que elijas.
6. Los resultados los encontrarás en la consola.
